## PDF 生成管线的坑（复用时必读）

- 用 pdf skill 的 `html2pdf-next.js`（Playwright），**不要**手写 Playwright 脚本。
- **HTML 里 class 不能叫 `cover`**（或 id=cover / data-role=cover）：脚本会误判为"封面页"强制分页，把版式切得稀碎（曾导致 2 页变 4 页）。用 `thumb` 之类。
- Playwright 已装在 pdf skill 目录 `document-skills/0.1.4/node_modules`，**版本必须锁 1.57.0**（对应 chromium build 1200，是 npmmirror 上有完整 win64 包的最新构建；更新的 1243 镜像缺 win64）。重装命令：`PLAYWRIGHT_DOWNLOAD_HOST=https://cdn.npmmirror.com/binaries/playwright npm install --no-save playwright@1.57.0 pdf-lib`（在 `document-skills/0.1.4` 目录下执行）。
- `npm install --no-save` 会清掉同目录其他包：playwright 和 pdf-lib **必须一条命令同时装**。
- Chromium 的 `page.pdf()` 会保留 `<a href>` 为可点击注释（已验证 29 个链接全部存在）。
- `pdf.py meta.set` 不能原地覆盖，要 `-o` 临时文件再 mv。
- 二维码用 `qrcode` npm 包（`.portfolio-assets/node_modules`），白底 chip 里 img 必须 `display:block`（否则基线空隙导致上下不等宽）。
- `check-html` 校验通过后再渲染；渲染后跑 `pdf_qa.py --no-tables`；视觉验收用 judge agent 看 PNG。
