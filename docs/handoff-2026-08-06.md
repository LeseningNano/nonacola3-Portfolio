## 项目概览

Next.js 16 (App Router + Turbopack) + Tailwind v4 + Prisma (Postgres) + next-auth。个人视频作品集站点，前台 + 管理后台（`/dashboard`）。

关键脚本（`package.json`）：
- `npm run dev` / `npm run build`（build = `prisma migrate deploy && next build`）
- 无 lint/typecheck 脚本 —— 验证用 `npx tsc --noEmit` + `npx next build`

## 重要约定

1. **每次改动都要 `git commit` + `git push`**（用户明确要求，直接在 master 上操作，不建分支）。
2. **不要提交**本地工件：`.opencode/`、`start-dsh.ps1`、`.superpowers/`、`dev-server.log`、`handoff-mobile-layout.json`。前两者当前未跟踪，勿 `git add -A` 带入。
3. `.env` 含真实数据库连接（本地 + 生产 Vercel Blob 凭据），勿提交。
4. 桌面端首页滚动是**容器滚动**：`#main-scroll`（`md:h-screen md:overflow-y-auto`）承载滚动；移动端才是 window 滚动。这是站内多处滚动逻辑的前提。
