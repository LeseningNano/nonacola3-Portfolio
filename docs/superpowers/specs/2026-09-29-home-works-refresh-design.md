# 首页与 Works 页统一改版 + 动效 设计

- 日期：2026-09-29
- 设计稿：Design 画布 <https://claude.ai/artifact/HeEzFFVpCrbx3WYCPVh4tE>（首页桌面/移动、Works 桌面/移动、共用设计系统、动效方案六张画板；用户已确认）
- 状态：已确认方向，待实施

## 目标

让首页与 `/works` 看起来是同一个网站：沿用现有的简洁黑白风格，统一章节标题、作品卡片、列表行与导航；在此基础上加入一组克制的动效。

## 视觉原则（沿用现状，不引入新风格）

- 只用黑白灰：底色 `#0a0a0a`，面板 `neutral-900`，线 `neutral-800`，正文 `white` / `neutral-300` / `neutral-400`。**不加强调色。**
- 字体不变：正文 Inter；首页 Hero 名字 Montserrat；章节标题与 logo 用 Bitcount（`var(--font-bitcount)`），小写加句号。
- 直角、1px 细线、细边框按钮、无阴影。
- 固定中文文案保持现有字符串（如「精选视频作品与创作项目」「最新动态」「了解更多 & 合作洽谈」）；作品内容不翻译。

## 结构改动

### 共用元素

1. **章节标题 `SectionHeading`**：Bitcount 小写标题 + 一行浅灰副标题，两页共用。首页 `works.` / `news.` / `about.`；Works 页新增 `selected.` / `archive.`，副标题使用现有本地化文案（`copy.selected.heading` / `copy.archive.heading`）。
2. **作品卡片 `WorkCard`**：16:9 缩略图在上，下方标题 + 「分类 · 年份」元信息，可选摘要与「Role / Tools」一行。缩略图不再叠字。首页与 Works 精选共用；缩略图容器保留 `data-vt-id`，现有缩略图飞入转场继续生效。
3. **列表行**：新闻列表与全部作品列表共用「底色从左铺满」的悬停效果（`.row-sweep`）。

### 首页

- `works.` 区：去掉跑马灯、漂移、「显示全部作品」展开与年份筛选；改为整齐网格，桌面 3 列、平板 2 列、手机 1 列，最多 6 个作品（按后台顺序取前 6 个），手机只显示前 3 个。右上 `ALL WORKS →` 跳转 `/works`；首页卡片链接继续带 `?from=home`。REEL 条保留在网格下方。
- `news.` / `about.`：只换章节标题组件与列表行悬停；布局不变。
- Hero：布局不变，加入名字逐字入场（见动效）。

### Works 页

- 开场大字介绍、语言切换、Showreel 保持现有布局。
- `Selected Works` 从左右交替大行改为两列卡片网格（手机 1 列），用共用 `WorkCard`。
- `All Works` 列表保持编号 + 标题 + 分类 + 箭头的有序列表语义，换成共用行悬停样式。
- 联系区与页脚不变。

### 导航

- 桌面（≥768px）：logo 左侧，右侧改为常驻 `WORKS · NEWS · ABOUT` 文字链接，替换现在的汉堡按钮与右侧抽屉。手机保持现有汉堡菜单与全屏面板。
- 语言切换仍只在 `/works`，位置不变。**首页中英切换不在本轮范围**（首页的中文介绍是作者原文，没有英文版本）。

## 动效（均在 `prefers-reduced-motion: reduce` 下关闭，内容直接可见）

| # | 效果 | 细节 |
|---|---|---|
| 1 | Hero 入场 | 名字逐字从遮罩下升起，字间隔 40ms；副标题 160ms 后、手机 CTA 与桌面按钮 280ms 后跟上。只在首次进入（有加载层时）播放；刷新 / 回访保持静态，避免已绘制内容闪烁。桌面首访的「开场轻推」流程保留，桌面按钮仍在轻推结束后出现。 |
| 2 | 章节标题解码 | 进入视口时播放一次：逐字出现，每个字先以乱码现身、350ms 后定格，字间隔 70ms。副标题在标题出到一半时（`floor(字数/2)×70+60ms`）开始，480ms 内从左向右擦出，同时由左侧 16px 滑到原位，**不上下移动、无短线**。 |
| 3 | 卡片依次揭示 | 进入视口时，卡片自下而上擦出并上移 24px；同排按列错峰 100ms。 |
| 4 | 卡片悬停 | 缩略图放大到 1.05、去掉 30% 暗化层、居中出现「▶ PLAY」、标题下划线从左画出。只在 `md` 及以上响应，触屏不粘住。 |
| 5 | 列表行悬停 | 底色从左向右铺满（450ms），文字变亮，箭头右移。无悬停能力的设备不显示。 |
| 6 | 导航滑动下划线 | 桌面导航下 1px 白线：`/works` 下固定在 WORKS；首页随滚动位置滑到当前板块（Hero 区时隐藏）；悬停时预览滑到悬停项。 |
| 7 | 视差 + 滚动进度线 | 保留现有 Hero 视差；在首页与 `/works` 的导航顶部加 1px 白色进度线。桌面以 `#main-scroll` 为准，手机以 window 为准。 |
| 8 | Showreel 呼吸环 | Works 页 Showreel 播放按钮外两圈细环缓慢扩散（2.4s，错开 1.2s），悬停放大 1.08；首页 REEL 条的 ▶ 同效果。 |
| 9 | 缩略图飞入转场 | 沿用现有 `ProgressBar` 的实现，不改。 |

## 不在范围

- 数据库、API、后台、鉴权均不改。
- 作品详情页、News 详情页不改（仍用旧 `VideoCard` 显示相关作品）。
- 页脚不改。

## 验收

- `npm test`、`npx tsc --noEmit`、`npx eslint app components lib tests proxy.ts` 通过（允许 5 条既有 warning）。
- 本地 dev 在 1280 与 375 宽度检查首页与 `/works`：动效按上表出现，开启减少动态效果后全部静止且内容可见。
- 不运行 `npm run build`；`npx next build --webpack` 如因 Google Fonts 网络失败，须如实标为未验证。
