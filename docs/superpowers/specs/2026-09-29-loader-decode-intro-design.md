# 首页加载画面：百分比解码开幕 设计

- 日期：2026-09-29
- 设计稿：Design 画布「开场 A · 解码开幕」<https://claude.ai/artifact/HeEzFFVpCrbx3WYCPVh4tE>（用户在 A/B/C 中选 A，并要求中央放百分比、到 100% 后乱码解码成原字）

## 时间线（首访、有加载层时）

| 阶段 | 起止（ms） | 画面 |
|---|---|---|
| count | 0–1000 | 中央 Bitcount 大字 `000%`→`100%`（缓出）；底部细线同步增长 |
| full | 1000–1180 | 停在 `100%` |
| morph | 1180–1990 | `100%` 四个位置立刻变乱码，多出的位置每 40ms 出现一个，第 i 个字在 250+70i ms 定格为 `nonacola3` 的原字 |
| hold | 1990–2190 | 停在 `nonacola3` |
| seam | 2190–2410 | 文字淡出，屏幕中线一道 1px 白线从中间展开 |
| open | 2410–3110 | 上下两半黑幕拉开（700ms），露出 Hero；此刻通知 Hero 名字逐字升起 |
| done | 3110– | 卸载加载层，桌面端开始原有「开场轻推」 |

底部一行：左 `VIDEO PORTFOLIO`，中细进度线，右 `VER 04 · © 年份`。原有 CODING / DESIGN / HOST 信息块移除。

## 约束

- 仍只在当次会话首次进入首页时播放（`sessionStorage` 的 `hero-loaded`）；`<head>` 的黑色 pre-loader 不变，加载画面从纯黑开始以便无缝衔接。
- 开启「减少动态效果」时跳过加载画面：直接显示首页、按钮与导航。
- 时间线由 rAF 驱动，回调存在 ref 中：父组件重渲染不会打断时间线（修复旧实现偶发卡在 100% 的问题）；后台标签页暂停、回到前台继续。
- 只用黑白灰；字体沿用 Bitcount。
